# Changelog — OlcRTC Manager Panel

История изменений панели управления OlcRTC Manager.

## 1.0.0

### Что нового
- **Обновление панели**: колонка «Обновление» в настройках — показывает установленную и доступную версию, кнопки «Проверить обновление» и «Обновить» (при наличии новой версии). Лог изменений отображается под строками версий.
- **Engine SFU**: добавлена поддержка `engine-name`, `engine-url`, `engine-token` — при создании/редактировании LOCATION (SFU) можно указать параметры внешнего движка.
- **CI**: автоматическая проверка соответствия конфигурационной схемы апстриму (workflow `upstream-check.yml`).
- **Update mode**: установщик `install.sh` автоматически определяет существующую установку и предлагает вариант обновления без переустановки.
- **Удаление устаревшего поля `data`**: миграция конфига убирает `data` из всех LOCATION; в JSON теге добавлено `omitempty`.
- **Опциональное поле данных**: `data` больше не создаётся по умолчанию при добавлении LOCATION.
- **Показ количества пиров**: в таблице LOCATION отображается текущее количество пиров upstream olcrtc.
- **Обработка изменений в генерации комнат**: поддержка актуального формата апстрима.
- **HTTPS**: панель доступна по HTTPS с самоподписанным сертификатом.
- **Внешний доступ**: панель по умолчанию слушает на внешнем интерфейсе (0.0.0.0).
- **UUID генератор**: Jitsi room URL разбит на сервер и room ID, добавлен генератор UUID.
- **Удалён Jazzy**: удалён неиспользуемый провайдер, исправлена совместимость wbstream.
- **Clipboard**: исправлен fallback при копировании.
- **Simplification**: упрощена структура конфига, исправлено отображение порта при переустановке.
